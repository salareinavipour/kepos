# Session 8: Using Philosophical Tools

## Aim

The common tools of philosophical argument: intuitions, examples, test
cases, counterexamples, evidence. Students construct their own example for
an abstract claim, then a counterexample to it.

## Pre-reading

- Thomson, Judith Jarvis (1971), "In Defense of Abortion" (part 1).

## Background reading

- Levy (2025); Curry (2025), "Thought Experiments," "Case Studies."
